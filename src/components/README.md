# src/components
## Purpose
Contains reusable components shared across features and layouts, grouped by module/context.
## Allowed Folders
- `ui/` (base components like buttons, inputs)
- `layout/` (navigation bars, footers)
- `shared/` (app-wide custom reusable components)
- `marketplace/` (marketplace components)
- `dashboard/` (seller/buyer dashboard elements)
- `admin/` (admin portal components)
