# src/pages
## Purpose
Visual page entry points mapped to routes, organized by user scopes.
## Allowed Folders
- `public/` (unauthenticated pages: about, contact, pricing, home)
- `auth/` (login, registration, password recovery)
- `dashboard/` (authenticated buyer/user dashboard pages)
- `seller/` (specialized seller pages)
- `admin/` (admin portal pages)
