# src/utils
## Purpose
Pure helper functions, formatters, validation utilities, and non-reactive functions.
## Allowed Files
- Utility scripts (e.g. `formatters.ts`, `validation.ts`)
## Naming Conventions
- camelCase or kebab-case (e.g. `cn.ts`, `format-date.ts`)
- Component or file exports should be lowercase functions
- Example: `export const formatCurrency = (val: number) => ...`
